# MCU 指令集与外设用法说明（v2.0）

> 配套版本：MCU v2.0（2026-08-16）。在 v1.3 基础上：ROM 扩到 4096 字节（PC 16 位）、
> ins_rom 合并 if_reg 变 BRAM 同步读、指令长度 1–4B 改 2–5B、跳转/分支扩到 5B（bytmov 12 位）、
> 总线地址映射改前 4 位、data_ram 扩容 16KB。
> 设计演进、时序与调试记录见 `版本开发日志/single_mcu_design_v2.0.md`。
> 编码来源：`decoder.v` / `pc.v` / `reg_f.v` / `single_mcu_top.v` / 各外设 `.v`。

---

## 1. CPU 指令集

### 1.1 编码规则

- 指令字节 0 = `opcode[5:0] << 2 | len[1:0]`，其中 **`len = 字节数 − 2`**（0–3，byte0 低 2 位定指令长度）。
- **指令长度 2–5 字节**（v1.3 为 1–4 字节）：
  - **2B**：HALT / NOP / IRET / JALR（`byte0 | 0x00`）
  - **4B**：ALU-R / ALU-I / LBU / SB
  - **5B**：跳转类（LJAL / RJAL / 6 条分支）
- 指令空间 **16 位（PC 0x000–0xFFF，4096 字节 ROM）**；寄存器号、立即数仍 8 位（0–255）。

### 1.2 字节布局

| 类别 | 长度 | byte0 | byte1 | byte2 | byte3 | byte4 |
|------|------|-------|-------|-------|-------|-------|
| 控制（HALT/NOP/IRET/JALR） | 2B | op | 0x00 | — | — | — |
| ALU-R | 4B | op | rd | rs1 | rs2 | — |
| ALU-I | 4B | op | rd | rs1 | imm8 | — |
| LBU / SB | 4B | op | rd / rs | 地址高 8 位 | 地址低 8 位 | — |
| 跳转（LJAL/RJAL） | 5B | op | `bm[11:4]` | 0x00 | 0x00 | `{bm[3:0],4'b0}` |
| 分支（LBEQ 等） | 5B | op | `bm[11:4]` | r1 | r2 | `{bm[3:0],4'b0}` |

> **bytmov 12 位有效**：`byte1 = bm[11:4]`、`byte4 高半字节 = bm[3:0]`（byte4 低 4 位固定 0）。
> decoder 拼 `bytmov = {inst_raw[31:24], inst_raw[7:4]}`，有效 ±4095，**一跳可贯通整个 4KB ROM**。

### 1.3 指令总表

| 类别 | 助记符 | opcode | byte0 | 长度 | 功能 |
|------|--------|--------|-------|------|------|
| 控制 | HALT | 0x00 | 0x00 | 2B | 停机（frz 停 PC） |
|      | NOP | 0x14 | 0x50 | 2B | 空操作（if_reg 冲刷时自动插入） |
|      | IRET | 0x15 | 0x54 | 2B | 中断返回：恢复断点 |
| 跳转 | LJAL | 0x08 | 0x23 | 5B | 向后跳，压栈保存返回地址 |
|      | RJAL | 0x09 | 0x27 | 5B | 向前跳，压栈保存返回地址 |
|      | JALR | 0x13 | 0x4C | 2B | 弹栈并跳转到 ra（调用返回） |
| 分支 | LBEQ | 0x16 | 0x5B | 5B | r1==r2 则**向后**跳 |
|      | RBEQ | 0x17 | 0x5F | 5B | r1==r2 则**向前**跳 |
|      | LBNE | 0x18 | 0x63 | 5B | r1≠r2 则**向后**跳 |
|      | RBNE | 0x19 | 0x67 | 5B | r1≠r2 则**向前**跳 |
|      | LBLTU | 0x1A | 0x6B | 5B | r1<r2（无符号）则**向后**跳 |
|      | RBLTU | 0x1B | 0x6F | 5B | r1<r2（无符号）则**向前**跳 |
| ALU-R | ADD | 0x02 | 0x0A | 4B | rd = r1 + r2 |
|      | SUB | 0x04 | 0x12 | 4B | rd = r1 − r2 |
|      | AND | 0x05 | 0x16 | 4B | rd = r1 & r2 |
|      | OR | 0x06 | 0x1A | 4B | rd = r1 \| r2 |
|      | XOR | 0x07 | 0x1E | 4B | rd = r1 ^ r2 |
|      | SLL | 0x0D | 0x36 | 4B | rd = r1 << r2[2:0] |
|      | SRL | 0x0E | 0x3A | 4B | rd = r1 >> r2[2:0]（逻辑右移） |
|      | SLTU | 0x11 | 0x46 | 4B | rd = (r1<r2)? 1 : 0（无符号） |
| ALU-I | ADDI | 0x01 | 0x06 | 4B | rd = rs1 + imm |
|      | SUBI | 0x03 | 0x0E | 4B | rd = rs1 − imm |
|      | ANDI | 0x0A | 0x2A | 4B | rd = rs1 & imm |
|      | ORI | 0x0B | 0x2E | 4B | rd = rs1 \| imm |
|      | XORI | 0x0C | 0x32 | 4B | rd = rs1 ^ imm |
|      | SLLI | 0x0F | 0x3E | 4B | rd = rs1 << imm[2:0] |
|      | SRLI | 0x10 | 0x42 | 4B | rd = rs1 >> imm[2:0]（逻辑右移） |
|      | SLTIU | 0x12 | 0x4A | 4B | rd = (rs1<imm)? 1 : 0（无符号） |
| 访存 | LBU | 0x1C | 0x72 | 4B | 读 16 位地址 → rd（RAM 或外设） |
|      | SB | 0x1D | 0x76 | 4B | rs 写入 16 位地址（RAM 或外设） |

> **opcode 从 v1.3 的稀疏值改为连续编号**（如 ADD v1.3=0x02/v2.0=0x02 但 byte0 变 0x0A；SB v1.3 byte0=0x77/v2.0=0x76），
> **v1.3 的 ins_rom.hex 不能直接用**，需用新汇编器（`tools/asm.py`）重新生成。

### 1.4 跳转偏移 bytmov 与覆盖极限

bytmov 是相对**指令末尾**（`指令地址 + 指令长度`）的 **12 位无符号偏移**：

- **R 前缀（向前）**：`bytmov = 目标 − (指令地址 + 长度)`
- **L 前缀（向后）**：`bytmov = (指令地址 + 长度) − 目标`

**覆盖极限**（v2.0 ROM 4096 字节）：

- bytmov 12 位 → **每一跳/分支最多 ±4095 字节**（编码 `{byte1, byte4[7:4]}` 12 位，5B 跳转/分支专用）。
- 前向最远 `addr+len+4095`，后向最近 `addr+len−4095`——**0x000 ↔ 0xFFF 一跳贯通**，不再需要 v1.3 的链条式中转。
- 5B 跳转的 byte2/3 为 0；分支的 byte2/3 为 r1/r2（RISC-V 风格：寄存器在前、绝对目标最后）。
- 汇编器自动算 bytmov，越界时报错并提示换方向。

### 1.5 寄存器与栈约定

| 项 | 约定 |
|----|------|
| r0 | 恒为 0（写无效，作零寄存器用） |
| r1–r253 | 通用寄存器 |
| r254 | 空闲可用 |
| r255 | 只读：UART tx_busy（bit0，轮询发完用） |
| 调用栈 | **硬件栈**（reg_f 内 `rad`，**16 位槽位**），深 255；满/空由 j_flag 保护——LJAL/RJAL 压栈、JALR 弹栈 |
| PC | **16 位 0x000–0xFFF**（ROM/程序区独立于总线地址空间） |

## 2. 外设与地址空间

### 2.1 地址空间总表（总线地址前 4 位解码）

| 区间 | 设备 | LBU（读） | SB（写） |
|------|------|-----------|----------|
| 0x0000–0x1FFF | 未定义 | 黑洞（返回 0） | 黑洞（丢弃） |
| 0x2000–0x2FFF | UART | 弹 RX FIFO 队首 → rd | 触发 TX 发送 |
| 0x3000–0x3FFF | timer | 黑洞（返回 0） | 重装 / 模式 / ack |
| 0x4000–0x4FFF | GPIO | 读 IN 引脚电平 → rd | 推挽输出 / 单 pin 模式 |
| 0x5000–0x7FFF | 未定义 | 黑洞 | 黑洞 |
| 0x8000–0xBFFF | data_ram | 读 RAM → rd | 写 RAM |
| 0xC000–0xFFFF | 未定义 | 黑洞 | 黑洞 |

> **v2.0 地址映射改前 4 位**（v1.3 为前 3 位）；外设地址全部重排（UART 0x4000→0x2000、timer 0x6000→0x3000、GPIO 0x8000→0x4000、data_ram 0x2000→0x8000）。
> 总线访问均为 2 拍（RAM 存 stall 1 拍；UART/timer/GPIO 无 stall）。

### 2.2 data_ram（0x8000–0xBFFF，16KB）

| 指令 | 示例 | 行为 |
|------|------|------|
| LBU rd, addr | `LBU r2, 0x8000` | 读 RAM[addr] → rd |
| SB rs, addr | `SB r2, 0x8000` | RAM[addr] = rs |

- 容量 16KB（4 个 `ram_sec`，每区 `mem[0:4095]` 4KB），BRAM 块；上电全 0，无复位。
- `ram_top` 按 `bus_addr_in[15:12]`（1000–1011）识别为 RAM 区，`sec[bus_addr_in[1:0]]` 选 4 区之一。
- **已知限制**：选区用 `addr[1:0]`（低 2 位）而非页高 2 位，有效寻址可能只有 4KB（见设计记录 §9）。

### 2.3 UART（0x2000–0x2FFF，含 FIFO + 中断）

| 指令 | 地址 | 行为 |
|------|------|------|
| LBU rd | 0x2000 | 弹 RX FIFO 队首 → rd（FIFO 空时返回 0） |
| SB rs | 0x2000 | 触发 uart_tx 发送 rs 字节（电平使能，下拍撤除） |
| 轮询等发完 | r255 | `LBNE r255, r0, 自旋` 直到 tx_busy 归 0 |

- **RX FIFO**：64 深（有效 63 字节），新帧不会覆盖未读旧帧。
- **中断**：`rx_irq = FIFO 非空`（电平）→ 中断源 0，向量 **0xE0**。ISR 每 `LBU r,0x2000` 弹一个字节，读到 FIFO 空为止。
- 发方向仍可中断内做：ISR 里 `SB rs,0x2000` 回发。

### 2.4 timer（0x3000–0x3FFF，纯写，32 位）

| 指令 | 地址 | 行为 |
|------|------|------|
| SB rs | 0x3000 | 设重装值**字节 0（最低）** |
| SB rs | 0x3001 | 设重装值字节 1 |
| SB rs | 0x3002 | 设重装值字节 2 |
| SB rs | 0x3003 | 设重装值**字节 3（最高）** |
| SB rs | 0x3004 | 设 irq 模式：**数据** bit0=0 脉冲（1 拍，错过丢）/ bit0=1 电平锁存 |
| SB rs | 0x3005 | **ack**：清 timer_irq（仅电平模式有效；不重置当前计数） |

- 计数从 0 数到重装值 → **全 32 位相等**时 `timer_irq=1` 并清零归 0，**周期 = 重装值 + 1 拍**。
- 例：周期 65536 拍 → 重装值 0x0000FFFF（0x3001=0xFF、0x3000=0xFF；高位字节复位默认 0）。
- 关闭：重装值 = 0x00000000 不计数；任一字节非 0 即计数（`||` 使能）。
- 中断：源 1，向量 **0xC8**，优先级高于 UART（irq_bus 后判定覆盖）。
- 写 0x3004 时总线上的**数据值**（而非地址）决定模式——`SB r0,0x3004` 切脉冲、`SB rN(rN bit0=1),0x3004` 切电平。

### 2.5 GPIO（0x4000–0x4FFF，8 位）

| 指令 | 地址 | 行为 |
|------|------|------|
| LBU rd | 0x4000 | 读引脚：bit↔pin 一一对应，**仅 IN 模式**引脚回电平，其余位恒 0 |
| SB rs | 偶数地址（bit0=0，如 0x4000） | 推挽输出：data[i]→pin i，8 位统一操作，仅 OUT 模式引脚生效 |
| SB rs | 奇数地址（bit0=1，如 0x4001） | 单引脚模式设置：`addr[3:1]` 选 pin，`data[3:0]` 选模式 |

模式编码（data[3:0]）：

| 值 | 模式 | 引脚行为 |
|----|------|----------|
| 0000 | UNUSE（上电默认） | 未使用（驱动 0） |
| 0001 | OUT 推挽输出 | 驱动 `gpio_output` |
| 0010 | IN 轮询输入 | 高阻，电平可经 LBU 读回 |
| 0011 | IRQ 中断输入 | 高阻，电平式触发中断 |
| 0101 | TX（UART 发送） | 驱动引脚跟随 uart_tx 的 `tx`（等同输出） |
| 0110 | RX（UART 接收） | 高阻，引脚电平直送 uart_rx 的 `rx` |

- **方向**：mode[1]=0（UNUSE/OUT/TX）驱动、mode[1]=1（IN/IRQ/RX）高阻读入。
- **UART 整合**：tx/rx 已并入 GPIO 引脚（TX=0x05 / RX=0x06），不再有独立 UART 引脚。
- **中断分组**：pins 0–3 → GPIO1（`gpio_irq[0]`，向量 0xA8）；pins 4–7 → GPIO2（`gpio_irq[1]`，向量 0x88）。
  电平式持续触发、无 ack 寄存器；pin 保持低即反复进 ISR。
- **非 OR**：同组多个 IRQ pin 同时有效时只有最后一个生效（有限），建议**最多 2 个有效 IRQ pin**（每组 1 个）。

### 2.6 中断与向量

| 中断源 | irq_bus[5:3] | 子源 irq_bus[2:0] | 向量 | ISR 区间 | 优先级 |
|--------|--------------|-------------------|------|----------|--------|
| UART RX（FIFO 非空） | 001 | 000 | 0xE0 | 0xE0–0xF7 | 低 |
| Timer | 010 | 000 | 0xC8 | 0xC8–0xDF | 中 |
| GPIO1（pins 0–3） | 010 | 001 | 0xA8 | 0xA8–0xBF | 高 |
| GPIO2（pins 4–7） | 010 | 010 | 0x88 | 0x88–0xA7 | 高 |

- **向量不变**（沿用 v1.3）：`irq_vex` 存的 10 位字面量 992/968/936/904 经 8 位数组**截断**后有效值为 0xE0/0xC8/0xA8/0x88。改布局要连程序里的 `.org` 一起改。
- **授权门控**：`bytmov == 0`（仅在干净指令边界，如 NOP 授权点）才响应——grant 时保存断点 `pc_addr`、跳向量并冲刷流水线。
- **优先级**：GPIO > Timer > UART，由 single_mcu_top 的 irq_bus 后判定覆盖（同拍多源时高者胜）。
- **不可重入**：irq_controller 三态机（IDLE/IRQ/BACK），IRET 捕获后回写断点再开放。
