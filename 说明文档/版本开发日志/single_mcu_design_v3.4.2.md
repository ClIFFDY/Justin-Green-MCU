# MCU 设计记录（v3.4.2 —— OLED 主界面交互 / UART 115200 / STATUS 多页 / 游戏按键调整 / UPTIME 小时:分钟）

> 指令集速查见 `指令集说明/mc_v3.4.2_ins.md`（ISA 编码不变，重命名一份）。

## 1. UART 115200（v3.4.2）

- uart_top.v 波特率由地址位 `[11:10]` 选择（`==2'b01` → 115200，否则 9600）。
- `.equ UART 0x2000 → 0x2400`（putc/fast_putc/uart_isr 全部走 0x2400 → 115200）。
- `.equ DMA_DES 0x7320 → 0x7324`（DMA des 高字节 0x24 → 目标 0x2400，游戏帧同步 115200）。

## 2. 删除 boot BOK/M 调试（v3.4.2）

- boot 的 `putc 'B'/'O'`（起点/oled_init 完成）+ 中断就绪 `'K'` + 主菜单画完 `'M'` 全部移除。
- 保留 P15 闪 2 下（oled_init 完成指示）。

## 3. OLED 主界面交互（v3.4.2）

- **主菜单按 `0` 关屏**：置 `SCREEN_OFF@0x8436` + 发 SSD1306 `0xAE`（Display OFF）。
- **关屏期间 shell_parse 顶部加门控**：非 `0` 键一律静默忽略；`0` → 清标志 + 发 `0xAF` + 重画主菜单。
- 状态由 boot 决定（不读硬件）。

## 4. 扫雷（v3.4.2）

- **光标初始 (1,1)**（原 0,0 在棋盘外 → 光标 index 为负/错位，"按2没反应"的根因之一）。
- **光标标志 `(内容)` → `>内容<`**（更明显）。

## 5. 俄罗斯方块（v3.4.2）

- **`7`（快速落底）移除** → **`2`（向下软落一格）**：`drop_piece` 单步 + render（到底自动固化出新块）。
- 控制注释同步 `2向下快移一格`。

## 6. STATUS 多页 + GPIO 状态（v3.4.2）

- **`4/6` 翻页**，`STATUS_PAGE@0x8437` 0-3 循环：
  - 页0：STATUS / CPU / UPTIME / MIPS / 按键提示（`2=MIPS 4/6=PAGE 0=BACK`，删重复 BACK）
  - 页1-3：**GPIO 状态**，每 pin 两行（`P0 UART_RX` + 缩进波特率），3 pin/页
- **GPIO 角色表 `GPIO_CONF@0x8450-0x8457`**：boot 复位时写入（P0 uart_rx P1 uart_tx P4 i2c_scl P5 i2c_sda P6 led_out 其余 unuse）——状态由 boot 决定，不读硬件。
- UART pin 第二行显示 `115200`，I2C pin 显示 `400K`。

## 7. UPTIME 小时:分钟（v3.4.2）

- **oled_uptime 重写**：总秒（16bit UPTIME_S0/S1）÷3600 → 小时（16 位除 0x0E10），余 ÷60 → 分钟，显示 **`HhMm`**（如 `0h4m`、`1h5m`、`12h34m`），秒舍弃（每 60s 才变，显示稳）。
- **每秒防御刷新 `uptime_disp_check`**（shell_loop 钩子）：
  - 恢复 `0x6008=3`（timer prio，防刷新绘制期间 resume 破坏导致 oled_irq_on 未完成 → timer 掩死 → UPTIME 冻结）
  - 清旧值区 → 重画 → `oled_flush_seg`（页模式**单次设列 + 连续流式**上传）
- **oled_flush_seg**：规避页模式分批设列在真机批2+ 失效（秒数列不更新）和横屏窗口切换破坏显示（闪一下消失）——单设列 + 靠 SSD1306 列自增连续流式（同 oled_flush_h 横屏流式验证过的方式）。

## 8. 分数 10 进制（v3.4.2）

- 新增 `fprint_dec`（帧版 16 位十进制，仿 print_dec），俄罗斯方块 `SCORE:` 从 hex → 10 进制。

## 11. 调试记录（v3.4.2）

- **UPTIME 秒卡 4s**：初判计数器被掩死（timer prio 被 oled_irq_off 掩掉后 oled_irq_on 未完成）→ 防御写每轮恢复 `0x6008=3` 解冻（速率正常）；秒不更新是显示上传问题（页模式分批设列批2+ 真机失效）→ 聚焦仿真强制 UPTIME_S0 确认刷新路径本身上传正确（93 字节覆盖值区）→ 换 `oled_flush_seg` 单设列连续流式。**仿真无法复现真机 SSD1306 分批设列失效**（显示模型处理正确），最终用户放弃秒显示改小时:分钟。
- **oled_dec16 高字节 bug**：聚焦仿真强制 UPTIME_S0 显示 "1m4s"（应为 5）→ 手算发现 16 位减法缺高字节 → 修复。
- **仿真加速**：tb 强制 pc 跳过 oled_init 上电延时（26×255×255 三嵌套 ≈ 5M 拍）→ boot 从 10.8M 拍降到 ~2.2M 拍（仿真快 5 倍）；force 范围需随固件汇编地址变化更新。
