# 单周期 CPU 设计记录（v1.0）

> 版本：2026-08-10  ·  实验性质，用于理解 CPU 基本原理  ·  仅实现 ADDI 一条指令

## 1. 设计目标

用 Verilog 手写一个最简单的单周期 CPU，验证：

- 取指 → 译码 → 读寄存器 → ALU 运算 → 回写 的完整数据通路
- 立即数 / 寄存器两种操作数来源的选择逻辑

## 2. 总体架构

```
        ┌─────────┐       ┌──────────┐
  clk ─▶│   PC    │────▶│  ins_rom │
  rst ─▶│ addr[7:0]│     └────┬─────┘
        └─────────┘           │ inst[7:0]
                              ▼
                        ┌──────────┐
        ┌──────────────▶│   reg_f  │─────▶ rs1_data[7:0]
        │  wdata[7:0]   │ (寄存器堆)│─────▶ rs2_data[7:0]
        │               └────┬─────┘
        │   ALU 回写         │ rs1_data/rs2_data
        │                    ▼
        │              ┌──────────┐
        └──────────────│   alu    │────▶ alu_res[7:0]
        imm_act ◀──────│  result  │
        (由 reg_f 输出) └──────────┘
```

## 3. 指令集设计（8 位指令）

```
   7    6 │  5   │  4 3  │  2 1 0
  ┌───┬───┐ ┌───┐ ┌───┬───┐ ┌───┬───┬───┐
  │      │ │   │ │      │ │          │
  │  op  │ │flag│ │ rs1 │ │ rs2 / imm│
  │ 2 bit│ │ 1b │ │ 2 bit│ │  3 bit   │
  └───┴───┘ └───┘ └───┬───┘ └────┬─────┘
                      │          │
      [7:6] opcode（2 位）→ 最多 4 种指令
      [5]   flag：0=立即数模式  1=寄存器模式
      [4:3] rs1（源寄存器 1，也是目标寄存器）
      [2:0] 立即数模式：3 位立即数（零扩展）
            寄存器模式：rs2 取 [3:2]
```

**目前只实现 ADDI**（立即数加法），编码为 `00_0_rs1_imm`。

## 4. 模块说明

### 4.1 pc.v —— 程序计数器

| 端口 | 方向 | 说明 |
|------|------|------|
| clk / rst | 输入 | 时钟 / 复位 |
| addr[7:0] | 输出 | 当前指令地址 |

- 复位 → 0；每个时钟上升沿 `addr + 1`
- 目前是纯递增，无跳转

### 4.2 ins_rom.v —— 指令存储器

| 端口 | 方向 | 说明 |
|------|------|------|
| addr[7:0] | 输入 | PC 给出的地址 |
| inst[7:0] | 输出 | 该地址的指令 |

- 256 字节 ROM，组合读 `inst = mem[addr]`
- `initial` 初始化程序（仿真用），当前只有一条有效指令：

```verilog
mem[0] = 8'b00_0_01_01_1;  // ADDI: rs1=01, imm=011(=3)  → r1 + 3
```

### 4.3 reg_f.v —— 寄存器堆 + 立即数标志译码

| 端口 | 方向 | 说明 |
|------|------|------|
| clk | 输入 | 时钟 |
| we | 输入 | 写使能（当前 top 中硬编码 1） |
| inst_raw[7:0] | 输入 | 指令（用于译码） |
| wdata[7:0] | 输入 | 写回数据（来自 ALU 结果） |
| rs1_data / rs2_data[7:0] | 输出 | 两个读口 |
| imm_act | 输出 | 立即数标志，送给 ALU |

- 4 个 8 位寄存器 `regs[0:3]`
- 寄存器 0 恒为 0：读侧 `rs==0 → 0`，写侧 `waddr != 0` 才写
- 译码：

```verilog
rs1     = inst_raw[4:3];
rs2     = (inst_raw[5]==1) ? inst_raw[3:2] : 2'b0;
imm_act = (inst_raw[5]==1) ? 0 : 1'b1;
```

- 写回（当前目标地址硬编码）：

```verilog
wire [1:0] waddr = 2'b11;          // 注意：写死到 r3
always @(posedge clk) begin
    if (we && waddr != 0) regs[waddr] <= wdata;
end
```

### 4.4 alu.v —— 运算单元

| 端口 | 方向 | 说明 |
|------|------|------|
| a[7:0] | 输入 | 源操作数 1（rs1_data） |
| b_raw[7:0] | 输入 | 源操作数 2（rs2_data） |
| imm_act | 输入 | 是否用立即数 |
| inst_raw[7:0] | 输入 | 指令（取立即数位） |
| result[7:0] | 输出 | 运算结果 |

- 操作数 B 选择：

```verilog
wire [7:0] b = (imm_act == 1) ? {5'b0, inst_raw[2:0]} : b_raw;
assign result = a + b;   // 目前只有加法
```

### 4.5 single_cpu_top.v —— 顶层连接

```verilog
pc    u_pc(.clk(clk), .rst(rst), .addr(pc_addr));
ins_rom u_ins_rom(.addr(pc_addr), .inst(inst));
reg_f u_reg_f(.clk(clk), .we(we), .inst_raw(inst),
              .rs1_data(rs1_data), .rs2_data(rs2_data),
              .wdata(alu_res), .imm_act(imm_act));
alu   u_alu(.a(rs1_data), .b_raw(rs2_data),
            .inst_raw(inst), .imm_act(imm_act), .result(alu_res));
```

## 5. 当前程序的数据流（仿真预期）

`mem[0] = 00_0_01_01_1`（ADDI r1, #3），寄存器已初始化 `regs[1]=5`：

| 信号 | 值 | 说明 |
|------|-----|------|
| inst[4:3] = 01 | rs1 = r1 | 读源操作数 |
| inst[5] = 0 | imm_act = 1 | 立即数模式 |
| inst[2:0] = 011 | ALU 的 b = 3 | 零扩展 |
| rs1_data | 5 | regs[1] |
| alu_res | 8 | 5 + 3 |
| regs[3] | 8 | 上升沿写回（目标被硬编码到 r3） |

> 注意：`regs[3]` 在第一个时钟上升沿**之后**才变为 8。

## 6. 当前已知问题 / 限制

| # | 问题 | 影响 |
|---|------|------|
| 1 | `waddr` 硬编码 `2'b11` | 结果总是写 r3，无法由指令指定目标寄存器 |
| 2 | `we` 硬编码 `1'b1` | 每周期都写寄存器，无写使能控制 |
| 3 | `rs2=inst[3:2]` 与 `rs1=inst[4:3]` 位域重叠 | 双寄存器操作数编码相互挤占 |
| 4 | opcode 仅 2 位 | 指令数上限 4，除非改变长指令 |
| 5 | ALU 只有加法 | 无 opcode 选择，无减法/逻辑运算 |
| 6 | 无跳转指令 | PC 只能顺序递增 |
