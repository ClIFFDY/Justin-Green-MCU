# MCU 设计记录（v1.3 —— ROM 512 字节 + timer 32 位 + 中断向量重排）

> 版本：2026-08-15（2026-08-16 增补 §8#6 timer 进位链与 §10 整机回归）
> MCU 系列第 4 版（v1.2 见 `single_mcu_design_v1.2.md`；CPU 系列见 `single_cpu_design_v6.5.md`）。
> **指令与外设速查见 `指令集说明/mc_v1.3_ins.md`**；本日志只记设计、时序与调试。
> 核心变化：
> ① **ROM 扩到 512 字节，PC 9 位**（v1.2 为 256 字节 / 8 位）；
> ② **reg_f 调用栈加宽到 9 位**（返回地址能覆盖 0x100–0x1FF 高区）；
> ③ **timer 扩到 32 位计数**（v1.2 为 16 位），寄存器表调整；
> ④ **ISR 向量重排**：GPIO2=0x88 / GPIO1=0xA8 / TIMER=0xC8 / UART=0xE0；
> ⑤ **汇编器支持 512**（ROM_TOP=0x1FF，hex 写满 512 字节）。

## 0. 版本说明

| 维度 | MCU v1.2（旧） | MCU v1.3（当前） |
|------|----------------|------------------|
| 指令空间 | 8 位，256 字节 | **9 位，512 字节（0x00–0x1FF）** |
| 调用栈 | 8 位 RA，深 255 | **9 位 RA，深 255** |
| timer | 16 位计数（cnt_set_h/l） | **32 位计数（cnt_set[0..3]）** |
| timer 寄存器 | 0x6000/1/2 重装低/高/模式，0x6003+ ack | **0x6000–3 重装[0..3]，0x6004 模式，0x6005 ack** |
| ISR 向量 | 0xA0 / 0xB8 / 0xD0 / 0xE8 | **0x88 / 0xA8 / 0xC8 / 0xE0** |
| 指令集 | 30 条 | 30 条（不变） |
| 汇编器 | ROM_TOP=0xFF | **ROM_TOP=0x1FF** |
| 上板程序 | ISR 0xA0–0xFF | **主程序 0x00–0x87 + 0x100；ISR 0x88–0xF2** |

## 1. ROM 512 字节 & PC 9 位

- `ins_rom.v`：`addr [8:0]`，`mem [0:511]`；`inst_raw = {mem[addr..addr+3]}` 4 字节连续取指。
- `pc.v`：`pc_addr / ra [8:0]`，复位/自增/跳转全 9 位；`bytmov` 仍 8 位（每跳 ≤ ±255）。
- `single_cpu_top.v`：`pc_addr / irq_addr / ra_fo / ra_ba` 全 9 位。
- `irq_controller.v`：断点保存 `pc_addr_in [8:0]`、内部 `pc_addr [10:0]`、`irq_addr 输出 [8:0]`。
- 程序区 0x00–0x1FF 共 512 字节，全部可执行；跳转目标范围随 ROM 顶放开（见 §5 覆盖极限）。

## 2. reg_f 调用栈 9 位

- `rad [0:255]` 槽位 9 位，`j` 9 位；压栈 `rad[j]<=ra_in; j<=j+1`，弹栈 `rad[j-1]<=9'b0; j<=j-1`。
- `ra = rad[j-1]` 单槽整存整取——返回地址（9 位）可指到 0x100–0x1FF 高区。
- 满/空保护沿用：`j_flag[1]=j==255`（满，不再压）、`j_flag[0]=j==0`（空，JALR 退化为顺序执行）。
- **修复**：曾把 RA 拆两槽存放（`rad[j]<={ra_in[0],7'b0}`、`rad[j+1]<=ra_in[8:1]`），重建公式 `{rad[j-2],rad[j-1][7]}` 与压栈不一致，弹栈只还原出 bit8（返回全到 0x000，死循环）。改回单槽 9 位整存后，低区 0x002、高区 0x1F2 返回地址均正确还原（仿真验证）。

## 3. timer 32 位

- `cnt_set[0:3]` / `cnt[0:3]` 4 字节小端（[0]=低字节）；计数 0x00000000 起，**全 32 位相等**触发 `timer_irq` 并清零归 0。
- 任一 `cnt_set[i] != 0` 即使能计数（沿用 v1.2 的 `||` 使能）；周期 = 重装值 + 1 拍。
- 寄存器（总线写，SB）：

| 地址 | 含义 |
|------|------|
| 0x6000 | cnt_set[0]（重装低字节） |
| 0x6001 | cnt_set[1] |
| 0x6002 | cnt_set[2] |
| 0x6003 | cnt_set[3]（重装高字节） |
| 0x6004 | irq_mode：bit0=0 脉冲（1 拍，错过丢）/ bit0=1 电平锁存（需 ack） |
| 0x6005 | ack：清 timer_irq（仅电平模式有效；不重置当前计数） |

- 中断：源 1，向量 **0xC8**，优先级高于 UART（irq_bus 后判定覆盖）。
- **修复**（4 处，均仿真验证）：① 写重装值曾用 `cnt_set[i]`（for 循环后 `i==4`，越界被丢弃，cnt_set 永写不进，timer 完全死掉）→ 改 `cnt_set[bus_addr_in[12:0]]`；② 匹配条件曾用 `||`（任一字节相等即触发，低字节为 0 时第 1 拍就触发并卡死计数）→ 改 `&&`；③ 匹配后清零 `for i<3` 漏掉 cnt[3] → 改 `i<4`；④ **进位链用 `for (i<3) if (cnt[i]==0xFF) cnt[i+1]++`**——cnt[1] 停在 0xFF 的那 256 拍里 cnt[2] 每一拍都自增，计数值冲过 0x0000FFFF 之后匹配条件 `cnt[2]==0 && cnt[3]==0` 与 `cnt[0]==0xFF && cnt[1]==0xFF` 永不同拍成立 → **重装值 ≥0x00010000 时 timer_irq 永不触发**（整机回归 Phase5 LED 永不灭）→ 改逐级显式进位（`cnt[0]+1`；`cnt[0]==0xFF → cnt[1]+1`；`cnt[0]&&cnt[1]==0xFF → cnt[2]+1`；`cnt[0]&&cnt[1]&&cnt[2]==0xFF → cnt[3]+1`），只有全低字节在最高位时才进高位，重装 0x0000FFFF 精确 65536 拍触发。

## 4. ISR 向量重排

| 中断源 | 向量 | ISR 区间 | 优先级 |
|--------|------|----------|--------|
| GPIO2（pins 4–7） | 0x88 | 0x88–0xA4 | 高 |
| GPIO1（pins 1–3） | 0xA8 | 0xA8（占位 IRET） | 高 |
| Timer | 0xC8 | 0xC8–0xDD | 中 |
| UART RX | 0xE0 | 0xE0–0xF2 | 低 |

- `irq_vex` 里存的字面量是 992/968/936/904（10 位），数组 `reg [7:0] irq_vex` 是 8 位宽 → **取低 8 位**后有效值即上表 0x88/0xA8/0xC8/0xE0。这是按截断效果确定的布局（见 §8 #5），依赖隐式截断，属已知脆弱点（见 §9）。
- 槽间隔 32 字节，实际 ISR 体 19–29 字节互不重叠；主程序区 0x00–0x87 + 0xF8–0x1FF。

## 5. 跳转覆盖极限（512 ROM 的关键约束）

- `bytmov` 仍 8 位（0–255），**每一跳/分支最多 ±255 字节**；方向由 opcode[0] 决定（L=后、R=前），相对指令末尾（addr+len）。
- 前向最远 `addr+len+255`，后向最近 `addr+len−255`。512 ROM **一跳贯通不了**：
  - 从 0x000 出发前向极限 ≈ 0x101；从 0x1FF 出发后向极限 ≈ 0x102；0x000↔0x1FF 必须**链条式跳转**（经中转地址分段）。
- 实测链路（仿真）：`0x000 → 0x0FE（bm=0xFA）→ 0x1F0（bm=0xF0）`，每段都在 ±255 内，跨边界逐段落对。
- 布局含义：高区代码（≥ 0x148）无法直接 `LJAL` 回 0x40 这类低区子程序（后向 bm>255）——上板程序把 send_char 放到 0x100，用**前向 RJAL** 调用（bm=0xBE），绕开该限制。
- 汇编写法不变（绝对目标地址），bytmov 由 asm.py 自动算；越界时汇编器直接报错，提示换方向或放中转。

## 6. 汇编器 512 支持

- `tools/asm.py`：`ROM_TOP = 0x1FF`，`.org`/跳转目标允许 0x00–0x1FF，`write_hex` 写满 512 字节（0x00–0x1FF 填 HALT）。
- 顺带新增边界检查：`place()` 校验 `addr + 长度 − 1 <= ROM_TOP`，防止指令末字节越 ROM 顶。
- 地址打印改 `%03X`（0x100+ 对齐）。用法不变：`python tools/asm.py 程序.asm -o 输出.hex`。

## 7. 上板程序重排（tools/board_test.asm）

新向量把 GPIO2 ISR 压到 0x88，原主程序（banner 结尾 0x88–0x8F）与它重叠，故整体重排：

| 区间 | 内容 |
|------|------|
| 0x00–0x3B | 初始化（pin 模式、r2=1 回环开、timer 32 位重装 0x0000FFFF + 使能） |
| 0x3C–0x7D | banner "cpu ready\r\n"（11 字符，ADDI+RJAL send_char） |
| 0x7E–0x83 | 主循环（NOP NOP LBEQ 自旋，中断授权点） |
| 0x88–0xA4 | GPIO2 ISR（KEY2 翻转 r2、去抖） |
| 0xA8 | GPIO1 ISR 占位（IRET，防误触发挂死） |
| 0xC8–0xDD | Timer ISR（LED 计数） |
| 0xE0–0xF2 | UART ISR（弹 FIFO、翻转大小写、回环开关） |
| 0x100–0x10D | send_char 子程序（高区，前向 RJAL 可达） |

- timer 寄存器表变化同步：irq_mode 0x6004、ack 0x6005（对应 §3）。
- send_char 挪到高区 0x100：banner（0x3C–0x7D）与 UART ISR（0xF0）都用 **RJAL 0x100** 前向调用（bm 分别 0xBE / 0x0E），JALR 返回；主程序整体还多出 0xF8–0x1FF 可用。

## 8. 调试记录（v1.3 修复项）

| # | 问题 | 修复 |
|---|------|------|
| 1 | reg_f RA 栈加宽时改拆两槽，重建公式 `{rad[j-2],rad[j-1][7]}` 与压栈不一致 → 弹栈只剩 bit8，返回全到 0x000（死循环） | 改回**单槽整存** 9 位（`rad[j]<=ra_in; j++`；`ra=rad[j-1]`），低区 0x002 / 高区 0x1F2 仿真还原正确 |
| 2 | timer 写重装值 `cnt_set[i]`，for 后 `i==4` 越界 → cnt_set 永写不进，timer 不计数 | 改 `cnt_set[bus_addr_in[12:0]]`（仿真确认 0x64 装载、第 100 拍触发） |
| 3 | timer 匹配用 `||`，任一字节相等即触发（低字节 0 → 第 1 拍触发并卡死） | 改 `&&` 全 32 位相等 |
| 4 | timer 匹配后清零 `i<3` 漏 cnt[3] | 改 `i<4` |
| 5 | irq_controller 向量字面量 992/968/936/904 与 8 位数组不符，截断后与 v1.2 向量（0xE8/0xD0/0xB8/0xA0）错位，上板会崩 | 按**截断有效值**定新布局 0x88/0xA8/0xC8/0xE0，重排上板程序 ISR 位置 |
| 6 | timer 进位链 `for (i<3) if (cnt[i]==0xFF) cnt[i+1]++`：cnt[1]==0xFF 的 256 拍里 cnt[2] 每拍自增，计数冲过 0x0000FFFF → 重装 ≥0x00010000 时匹配永不同拍成立，timer_irq 永不触发（整机回归 Phase5 LED 永不灭，探针 timer_irq_edges=0、cnt 冲到 0x01008000） | 改逐级显式进位（仅低字节全为 0xFF 才进高位），重装 0x0000FFFF 精确 65536 拍触发；重跑整机回归 Phase5 通过 |

## 9. 已知限制 / 后续

| 项 | 说明 |
|----|------|
| irq_vex 依赖截断 | 存储 10 位字面量到 8 位数组，靠隐式截断得到 0x88/0xA8/0xC8/0xE0，脆弱易读错；后续建议改干净的 8 位字面量（0xE0/0xC8/0xA8/0x88） |
| 跳转覆盖 ±255 | v1.3 主要约束；跨全 ROM 需链条跳转，高区回调低区子程序需 RJAL 前向或中转 |
| 双 GPIO 同触发 | 沿用 v1.2：`gpio_irq=2'b11` 向量索引越界，勿用 |
| 中断不可重入 | 沿用 v1.1（irq_busy 锁存，ISR 内不响应新中断） |
| timer 32 位 | 周期最大 0xFFFFFFFF+1 拍；16 位时期望 65536 拍的程序需保证 cnt_set[2]/[3]=0（复位默认 0） |

## 10. 仿真验证（整机回归，2026-08-16）

`sim_1/new/board_test_tb.v` 整机回归（iverilog，ins_rom.hex = 当前上板程序）：

| 阶段 | 内容 | 结果 |
|------|------|------|
| Phase1 | 上电 banner "cpu ready\r\n" 11 字节逐字符比对 | 11/11 OK |
| Phase2 | 回环开：发 a/B/5，收大小写翻转 A/b/0x15 | 3/3 OK |
| Phase3 | KEY2 按下→回环关：发 'a' 无回显 | OK |
| Phase4 | KEY2 再按→回环开：发 'x' 回显 'X' | OK |
| Phase5 | LED 亮 0.2s：pin6 低 → ~200ms 后高，r4 153→0 | OK |

- 结果 **21 通过 / 0 失败，ALL TESTS PASSED**；仿真 245.1ms 自然结束（未触发 600ms 兜底超时）。
- Phase5 的 0.2s = timer 周期 65536 拍（50MHz → 1.31072ms）× r4=153 递减 ≈ 200ms。
- 修复进位链后重装 0x0000FFFF **精确每 65536 拍触发一次**；此前 `for (i<3) if (cnt[i]==0xFF) cnt[i+1]++`
  使 cnt[2] 每拍自增、计数冲过匹配值，Phase5 LED 永不灭（见 §8#6）。
- 逐时钟追踪另确认主循环 LBEQ 自旋正常：pc 序列 `0x7E→0x7F→0x80→0x84(瞬态)→0x7E`，
  HALT@0x84 被 LBEQ 的 flush1 挡住不锁存、fsm 不冻结；timer ISR 每 1.31ms 打断一次并 IRET 返回。
