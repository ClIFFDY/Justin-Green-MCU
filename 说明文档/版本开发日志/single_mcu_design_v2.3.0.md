# MCU 设计记录（v2.3 —— 抢占式 RTOS 内核：irq 读/写路径 + regs[254]=j 调用栈分区 + 寄存器分块 + 共享子程序 + shell）

> 版本：2026-08-18/19（v2.2 归档后）。在 v2.2（中断时序修正）基础上**做抢占式 RTOS**：irq_controller 加 irq 读/写路径、reg_f 把返回栈指针映射到 regs[254]、调度器按任务分寄存器与调用栈、任意任务可共享调用打印子程序、任务0 跑命令行 shell。**非指令集改动**（无新 opcode），但 core 改动 4 文件。
> 指令集速查见 `指令集说明/mc_v2.3_ins.md`（本版无新指令，opcode 表同 v2.2；只补 r254=j 与 0x5000 读路径两处语义）；本日志只记设计、时序与调试。
> 核心变化（2026-08-18/19）：
> ① **irq 读路径**：irq_controller 组合块新增读分支——`LBU 0x5000/0x5001` 可读被抢占任务断点 slot0（调度器用）；读分支优先级高于派发分支（读撞派发→读赢）；
> ② **IRQ_W 写路径 + else-if 写在前**：时序块 IRQ case 写分支在派发分支**之前**——ISR 内 2 条紧邻 SB 到 0x5000 原子改写 pc_addr[0]（重定向），派发撞改写窗口写赢、被推迟派发补发；
> ③ **regs[254] = 返回栈指针 j**（reg_f.v）：返回栈指针从专用寄存器改为通用寄存器 254，指令可直接读写 → **调度器按任务存/取 j + rad 按任务分区（0-63/64-127/128-191）→ 每任务独立调用栈**，任意任务都能 LJAL/RJAL 调子程序；
> ④ **寄存器分块**：任务工作寄存器天然隔离（任务0 低 r1/r2+高 r17-r21、任务1 低 r3/r4+高 r22-r25、任务2 低 r5/r6+高 r26-r29），调度器 r12-r15 临时，**共享子程序 r7-r11**（调度器按任务保存/恢复这 5 个）→ 任意任务可调 putc/print_hex；
> ⑤ **抢占调度器**（timer ISR，5kHz）：读 slot0 → 存 PC+j+r7-r11 → CUR=(CUR+1)%3 → 载新任务 → 2×SB 改写跳转 → IRET；TCB 每任务 8 字节（PC_LO/HI/J/R7-R11）；
> ⑥ **shell**（rtos_shell.asm）：任务0=shell（8 槽 RX 环形缓冲 + 空闲超时执行 + help/cnt/led 命令），任务1/2=后台计数；
> ⑦ **汇编器自动修正**（asm.py）：bytmov 死区自动补 NOP、L/R 前缀方向自动翻转、`\b`/`\xNN` 转义。

## 1. irq 读路径（irq_controller.v 组合块新增）

### 1.1 契约（调度器读被抢占任务断点）

- 读区 0x5000–0x5FFF；slot = `bus_addr_in[4:1]`，byte = `bus_addr_in[0]`：
  - `0` → 低 8 位 `pc_addr[slot][7:0]`；
  - `1` → 高 4 位 `pc_addr[slot][11:8]`（放低 nibble）。
- slot0（IDLE 任务断点）= **0x5000（低 8 位）/ 0x5001（高 4 位）**，重建 `resume_pc = (r_hi & 0x0F) << 8 | r_lo`。
- **读分支优先级高于派发分支**（组合块 `else if (!bus_sig_in && addr==IRQ_W)` 先于 else 派发）→ 读撞派发时读赢、数据有效、派发推迟。**读无需拉低使能**。
- 用法：只在 ISR 内读固定 slot0、绝不在 IDLE 级读、绝不读栈顶（嵌套只动栈顶不动 slot0）。

### 1.2 验证

- slot0 读 TB：timer 派发 → ISR 两条 LBU 0x5000/0x5001 读回 == pc_addr[0]。期间修过解码 bug `[15:13]`→`[15:12]`（0x5000 的 [15:13]=010≠IRQ_W=0101，否则读/写全不命中）。

## 2. IRQ_W 改写 + else-if 写在前（irq_controller.v 时序块）

### 2.1 契约（ISR 内重定向跳转）

- ISR 内 2 条**紧邻** SB 到 0x5000 改写 pc_addr[0]：SB1→`pc_addr[0][11:8]`+stage→OPR；SB2 被 OPR 态无条件捕获 `pc_addr[0][7:0]`+stage→IRQ。IRET 读 `pc_addr[j-1]=pc_addr[0]` 跳转。
- SB1/SB2 必须相邻解码拍（OPR 只有 1 拍）。

### 2.2 else-if 顺序隐患（硬件问题，已修）

- 时序块 IRQ case 曾把**派发分支放在写分支前**（与组合块读相反）。UART/GPIO（prio2）派发撞上 SB1 写拍→派发赢、`pc_addr[0][11:8]` 没写进→SB2 被当第一条→目标变垃圾→IRET 跳垃圾。
- 修复：**写分支放派发分支前**（line 93 写先、line 97 派发后）。
- 验证（preempt_redirect_tb 自同步）：ISR 内检测垫层拍 `irq_en!=11` → force 高优先级中断撞改写窗口 → 写赢派发、pc_addr[0] 保持、被推迟派发补发、落地正确。关键：授权拍比写拍早 1-2 拍，真正"同拍"只在授权与写之间的 1-2 拍窗口内断言的中断——else-if 顺序从构造上保证写赢。

## 3. regs[254] = 返回栈指针 j（reg_f.v，调用栈分区）

### 3.1 改动

- 返回栈指针从专用 `j` 寄存器改为**通用寄存器 regs[254]**：LJAL/RJAL 压 `rad[regs[254]]` 且 regs[254]++、JALR 弹、`ra <= rad[regs[254]-1]`、满/空检测改看 regs[254]。
- **任意指令可读写 j**（ALU/LBU/SB 的 rd/rs 支持 254）：调度器 `ADDI r12, r254, 0` 读 j、`ADDI r254, r12, 0` 写 j。

### 3.2 每任务独立调用栈（rad 分区）

- rad[0:255] 按任务分区：**任务0 rad[0:63]、任务1 rad[64:127]、任务2 rad[128:191]**；boot 设 `TCB{1,2}_J = 64/128`、开头 `ADDI r254, r0, 0`（任务0 基址 0）。
- 调度器按任务存/取 j（TCB 每任务多 1 字节 J）→ **切任务 = 换 j，返回地址落各自区域，互不干扰**。
- **RTL 提醒**：regs[254] 复位未清零（老代码复位清 j，改后丢失；只 initial 清 regs[0:63]）——软件 boot 已写 j=0 兜底，建议 RTL 复位也清 regs[254]。
- **边角**：j_flag 满/空检测（j==255/j==0）对分区任务语义不准（任务1 空是 j==64），压弹配平不触发，要做严可按 CUR_TASK 算基址。

## 4. 寄存器分块 + 共享子程序（v1.1/v1.3）

### 4.1 寄存器分块（分支指令只用 r0-r15；ALU/LBU/SB 任意寄存器）

| 角色 | 低区（可分支） | 高区（ALU/LBU/SB） |
|------|--------------|---------------------|
| 任务0（shell） | r1/r2 | r17-r21 |
| 任务1（后台） | r3/r4 | r22-r25 |
| 任务2（后台） | r5/r6 | r26-r29 |
| 调度器 | — | r12-r15（临时） |
| **共享子程序** | **r7-r11**（调度器按任务保存/恢复） | — |
| 保留 | r254=j | r0=0, r255=tx_busy 只读 |

- **收益**：任务工作寄存器天然隔离 → 调度器不 save/load 任务主分区，TCB 只剩 PC+j+r7-r11；上下文切换从 ~60 条降到 ~27 条。
- **分支寄存器 4 位限制**：分支只能 r0-r15 → 高区计数器跨抢占需存任务自有寄存器（内联延迟循环用 `ADDI 低区, 高区, 0` 拷贝到低区再分支）。

### 4.2 共享子程序（r7-r11 暂存组）

- putc/print_hexdigit/print_hex/put_crlf **只用 r7-r11、参数走 r7**，调度器按任务保存/恢复这 5 个寄存器 → **任意任务可安全调用**（不会踩别的任务分区）。
- 代价：调度器每切换多 5 SB + 5 LBU（只这 5 个，任务主分区仍不存）。

### 4.3 调用栈教训（上板实测"只出 prem 就卡"）

- LJAL/RJAL 用**共享硬件返回栈**（非分区时代），任务1/2 也调用时 JALR 弹出别的任务返回地址 → 栈交叉。v1.2 分区后根治。

## 5. 抢占调度器（timer ISR @0x248，5kHz 抢占）

### 5.1 流程

```
sched_body:
    SB r0, TIMER_ACK              # ack 电平锁存
    LBU r13, SLOT0_LO             # 读被抢占任务断点
    LBU r14, SLOT0_HI
    LBU r15, CUR_TASK
    # 存旧任务: PC_LO/HI + j(regs[254]) + r7-r11  → TCB[CUR]
    ...TICK++...
    # CUR = (CUR+1) % 3
    # 载新任务: TCB[new] → r13/r14(PC) + 写回 j + r7-r11
    SB r13, IRQW                  # 2×紧邻 SB 改写 pc_addr[0]（[11:8]）
    SB r14, IRQW                  # （[7:0]）
    IRET                          # → 新任务断点
```

- **ISR 向量桩必须用不链接的 `RBEQ r0,r0,sched_body`**（RJAL/LJAL 会压返回栈污染任务区域；ra 坑：桩用 RJAL 则任务从 putc 的 JALR 返回跳进填充区卡死）。
- TCB 每任务 8 字节：PC_LO/PC_HI/J/R7/R8/R9/R10/R11（0x9008 起，3 任务连续）。
- 调度器被 UART（prio2）抢占：ISR 内嵌套不跳指令（抢占断点 pc-1），分支/IRET 前垫层。

### 5.2 上板踩坑

- **bytmov=0 落穿坑**：前向分支目标=W+2 不可编码（硬件判 bytmov=0 为不跳），多路分发落穿到共享标签时最近分支差 2 词 → 加 NOP 拉开到 +3（`__nw2`、`__sh_rdinc`、`__ur_winc`、`__ap_done` 多处）。
- 后向分支必须 L 前缀（RBNE→LBNE）、0x100+ 区调 putc 是后向须 LJAL。

## 6. shell（rtos_shell.asm，任务0）

### 6.1 架构

- 任务0 = shell（提示符 `> `、环形缓冲收字符、回显/退格 0x7F/0x08、行缓冲 LINE_BUF 8 字节 + CURSOR、解析分发）；任务1/2 = 后台计数（CNT1/CNT2 + 内联延迟）。
- 命令：`help`（列命令）/ `cnt`（`t=xxxx c1=xx c2=xx`，tick 上位时间 + 后台计数）/ `led`（翻转）/ 未知 → `?`。
- 共享子程序区 0x100（putc/print_hex 等）；append 分发在 0x2A0（ISR 与调度器之间的空闲区）。

### 6.2 UART RX 环形缓冲（8 槽）

- RX_RING0-7 + WR/RD 指针：**ISR 压（写 WR）、shell 弹（读 RD），各写各的指针 → 无数据竞争**（满/空误判自愈）。
- ISA 无索引寻址 → ring 访问按 WR/RD **展开 8 路分支**。
- 8 槽够撑 "help\r\n"（6 字节）突发；4 槽会因回显 TX 阻塞 + 抢占挤掉后缀（曾丢 '\r' 导致命令不执行）。
- 满判定 `(WR+1)&7 == RD`，空判定 `WR == RD`。

### 6.3 空闲超时执行（串口助手无回车）

- 串口助手发裸字节**无结束符** → 命令永不执行。**修法：IDLE_CNT 累计距上次字符的 tick 数，≥50 tick(≈10ms) 且行非空则自动执行**。
- **关键时序**：任务0 每 3 个 tick 才运行（round-robin）→ 必须 `SUB r7,r1,r2` 取 tick 差值累加（不能每 tick 减 1，否则实际 30ms 才超时）。有 `\r`/`\n` 也照常执行（LAST_CR 防 CRLF 双执行）。
- **布局教训**：idle 代码把 shell 核心（0x000 区）撑爆越过 `.org 0x100` → 与子程序重叠、boot 挂（PC 跳 0x90A）。汇编器不报错 → **加代码后必须查 0x0F0+ 是否仍是填充**。修法：append 分发移到 0x2A0。

## 7. 汇编器自动修正（asm.py）

把踩过的汇编坑变成硬性自动处理（三个现有程序回归字节一致）：

1. **bytmov 死区自动补 NOP**：前向分支目标恰在 word+2（L/R 双向 bytmov 都=0）时在目标 label 前自动插 NOP 拉开到 bytmov=1（固定点迭代；`force_first` 标记让 NOP 独占一词）。注意 **target=word+1 不是死区**（L 前缀 bytmov=1 可编，方向翻转可救），只有 word+2 需补 NOP；label 紧跟 .org 时跳过。
2. **L/R 前缀方向自动翻转**：分支前缀与目标方向相反自动翻编码（RBNE→LBNE 后向、LBNE→RBNE 前向），源码不变、编码纠正，汇总打印次数。
3. **字符转义补全**：`'\b'`=0x08、`'\a'`、`'\f'`、`'\xNN'` 字面量。

## 9. 已知限制 / 后续

| 项 | 说明 |
|----|------|
| 分支寄存器 4 位 | 分支只能 r0-r15；高区计数器须拷贝到低区再分支（任务内联延迟用 `ADDI 低,高,0`） |
| bytmov=0 死区 | 已由汇编器自动补 NOP（word+2 目标）；word+1 由方向翻转兜底 |
